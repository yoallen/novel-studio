# Story Canon: parked for future builds

Ideas Yolanda has approved for later. Nothing here is in the program yet. Newest first.

## AI only if you invite it (closer to selling)

- **An "I don't use AI" setting.** Hides every trace of the collaborator: no Ask about this, no Conversations prompts, no AI wording anywhere. With no key the program already sends nothing; this makes that visible.
- **Visible AI layers, chosen one by one.** Two kinds, shown separately:
  - Permissions, each switched on separately: Help me brainstorm, Teach me, Show me examples, Critique my work, Read my pages.
  - Boundaries, promises the program keeps whatever else is on: Don't write my story (also turns off Show me examples), Don't decide for me (always true; shown so writers can see it).
  - "I don't use AI" is simply every permission off.
- Marketing line to keep: "AI optional," never "AI-free." The program was built with AI, and some built-in teaching text was drafted with it.

## The phone version (after November)

- Android first, starting with the Samsung Galaxy S24 Ultra. Wrap the existing screens (Capacitor or similar); keep the core logic.
- The hard part is sync between phone and PC. Story Trail already records every change, which makes merging possible.
- S Pen handwriting into Capture fits the ink and pencil design.

## The home wall display (Q1 or Q2 2027)

- A wall monitor showing the big picture across Yolanda's whole world, with Story Canon as one page among several (Mama Dorothy, the morning paper, Q4 promises).
- Each app offers its own big-picture numbers; the wall collects them.
- Designed to be read from across the room: large type, few numbers, pages that rotate on their own.
- The drafting-progress view on Where was I becomes Story Canon's page.
